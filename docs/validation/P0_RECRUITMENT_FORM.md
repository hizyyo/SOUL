# P0 Recruitment Form

> Заполняется вне git. Не записывайте имя, email, компанию, личные задачи или историю чатов. В отчёт переносится только код участника (`P01`, `P02`...) и агрегаты.

## Скрининг

- Код участника: `P__`
- Дата контакта: `YYYY-MM-DD`
- Использует минимум два AI-клиента или регулярно web + coding AI: `да / нет`
- Готов к 30-минутной сессии и follow-up на day 7/day 28: `да / нет`
- Понимает, что тест проходит на synthetic или самостоятельно написанных задачах: `да / нет`
- Не ожидает автоматических действий, финансовых операций или облачной синхронизации: `да / нет`
- Не участвовал в разработке и не является сотрудником: `да / нет`
- Статус: `приглашён / согласился / назначен / отказ / не подходит`

## Согласие перед сессией

- `consent=yes/no`
- Участник предупреждён не вводить пароли, платежные данные, медицинские сведения, рабочие секреты и чужие персональные данные: `да / нет`
- Разрешение сохранить только агрегаты, время и обезличенную обратную связь: `да / нет`
