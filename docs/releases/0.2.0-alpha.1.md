# SOUL 0.2.0-alpha.1

**Status:** Draft pre-release notes  
**Release state:** Not tagged or published  
**Build channel:** Active development

SOUL `0.2.0-alpha.1` is the first repository-wide pre-release version that presents the implemented P0 prototype as one coherent product build. It is intended for development, demonstration, and controlled validation, not production distribution.

## Highlights

- Local-first desktop runtime with encrypted personal state.
- Guided calibration and inspectable typed entities.
- Purpose-scoped context compilation for supported AI clients.
- MCP and Chromium Browser Companion integration paths.
- Blind preference evaluation against a reviewed baseline.
- Deterministic policies, mediated local actions, and signed receipts.
- Windows build, packaging, sidecar, and installation verification.

## Verification

The repository quality workflow runs TypeScript checks, ESLint, Vitest, production builds, Browser Companion assembly, Rust formatting, Clippy, Rust tests, release checks, and Windows packaging verification.

## Known Limitations

- The Gateway is a local simulation and does not control arbitrary external services.
- Release binaries are not signed and no secure updater is published.
- macOS and Linux release paths are not validated.
- External product validation remains incomplete.
- The project is proprietary and no production support commitment is provided.
